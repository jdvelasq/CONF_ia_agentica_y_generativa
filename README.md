# IA generativa y agéntica

Presentación HTML para GitHub Pages, sin compilación ni dependencias.

## Uso

Desde la raíz del repositorio:

```sh
python3 -m http.server 8000
```

Abrir http://localhost:8000/. Navegar con las flechas; pulsar **F** para pantalla completa.

## Edición

- `slides/`: un archivo HTML por diapositiva.
- `slides.json`: orden de las diapositivas; actualizarlo al añadir, eliminar o reordenar.
- `style.css`: estilos compartidos y paleta Tableau 10.
- `slides.js`: carga y navegación.
- `index.html`: visor; no contiene diapositivas.
- `assets/`: imágenes y diagramas SVG.
