# LangChain

- La palabra chain no significa que el modelo “piense” mágicamente en una cadena.
- Describe un programa compuesto: la salida de un paso se convierte en entrada de otro.
- Algunos pasos pueden ser deterministas —formatear un prompt, consultar una base de datos.
- LangChain es un framework de aplicación para LLMs.
- No es un modelo de lenguaje, no entrena modelos y no reemplaza la API de OpenAI, Anthropic o un modelo local.
