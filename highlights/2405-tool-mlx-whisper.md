# MLX Whisper en Apple Silicon

- MLX es el framework de machine learning para Apple Silicon que Apple liberó como open source el 5 de diciembre de 2023.
- MLX Whisper es el puerto del modelo de speech-to-text Whisper (OpenAI) sobre ese framework.
- MLX Whisper depende de FFmpeg para decodificar el audio antes de pasarlo al modelo.
- La calidad depende fuertemente del tamaño del modelo.
