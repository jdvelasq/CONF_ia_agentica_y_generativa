# Assistants API y GPTs

- OpenAI anunció Assistants API y GPTs en DevDay el 6 de noviembre de 2023.
- Construir un asistente sobre Chat Completions obligaba a la aplicación a gestionar todo.
- Assistants API movió esa gestión a la plataforma.
- Es un paso hacia asistentes configurables y persistentes.
- La Assistants API fue retirada oficialmente el 26 de agosto de 2026 y ya no está disponible.
