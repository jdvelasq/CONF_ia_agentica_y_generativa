# Duix Avatar

- En diciembre de 2024 aparece el proyecto hoy conocido como duixcom/Duix-Avatar.
- El proyecto integra componentes de ASR/TTS y síntesis audiovisual para clonación y generación local de video.
- En 2026 el proyecto cambió oficialmente el nombre HeyGem → Duix.Avatar.
- El cambio de marca no debe interpretarse como nacimiento de un proyecto nuevo.
- Un avatar no constituye por sí mismo un agente.
