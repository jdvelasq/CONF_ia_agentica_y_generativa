# Draw Things

- Dentro de la app hay un navegador de modelos ("model zoo").
- Como regla práctica: empezar con SDXL para uso general.
- Ir a https://drawthings.ai/downloads/ 2.
- Escribir un prompt (y, si aplica, cargar una imagen de entrada para img2img/inpainting/ControlNet). 3.

Draw Things es una aplicación gratuita para macOS, iOS, iPad y Apple Vision, optimizada para Apple Silicon, que carga modelos de difusión localmente — no solo Stable Diffusion ([2208-model-stable-diffusion.md](2208-model-stable-diffusion.md)): su navegador de modelos integrado también ofrece SDXL, FLUX.1/FLUX.2, y otros modelos de imagen más recientes (Qwen Image, Z Image, LTX-2.3) — sin depender de ningún servicio cloud.
