# Content Writer: producción editorial con etapas y controles

- GitHub registra la creación de sociilabs/claude-content-writer el 24 de marzo de 2026.
- Es un sistema de skills para producir contenido con perfiles de marca.
- Su README declara compatibilidad con Claude Code, Claude AI, ChatGPT y Gemini.
- No inaugura la generación de texto ni el concepto de skills.
- Transformar un material docente o una explicación técnica previamente aprobada en una pieza para una audiencia definida.
