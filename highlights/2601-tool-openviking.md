# OpenViking

- En enero de 2026 se crea volcengine/OpenViking, una base de contexto para agentes que unifica conocimiento.
- Los agentes necesitan decidir continuamente qué información debe entrar en el contexto.
- OpenViking trata el contexto como una estructura navegable y no simplemente como un conjunto plano de embeddings.
- Esto es conceptualmente más amplio que una vector database o un sistema RAG tradicional.
- Ofrece integraciones mediante mecanismos como MCP, hooks, plugins y extensiones para diferentes agentes.
