# Microsoft AutoGen

- AutoGen es un framework de Microsoft Research para construir sistemas multiagente mediante conversaciones entre agentes.
- El trabajo se documenta en un paper de agosto de 2023 y el código se publica como proyecto open source poco después.
- Antes de AutoGen, function calling (2306-function-calling.md) ya permitía que un modelo pidiera una acción estructurada.
- Es uno de los primeros frameworks ampliamente adoptados para multi-agent orchestration.
