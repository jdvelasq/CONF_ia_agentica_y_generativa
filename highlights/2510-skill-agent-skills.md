# Agent Skills y artefactos reutilizables

- La unidad mínima es una carpeta con un archivo SKILL.md.
- Lo que faltaba era un mecanismo para que el agente descubriera y cargara.
- Agent Skills resuelve eso mediante progressive disclosure.
- Funciona en Claude.ai, Claude Code y la API, y Anthropic distribuye skills predefinidas para PowerPoint.
- Agent Skills no sustituye a MCP ni a las tools; añade una capa distinta de conocimiento reutilizable.
