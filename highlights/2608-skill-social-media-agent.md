# Social Media Agent Skills: distribución de contenido con revisión humana

- GitHub registra la creación de namddp/social-media-agent-skills el 5 de agosto de 2026.
- No introduce el formato de skills —documentado desde 2510-skill-agent-skills.md—.
- Las skills cubren perfiles de voz, análisis de fuentes, reutilización.
- El proyecto declara que no usa claves de APIs sociales, cookies del navegador ni publicación desatendida.
- El proyecto no publica los borradores: la decisión final y la operación de cada plataforma siguen siendo humanas.
