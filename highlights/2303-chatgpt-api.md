# API de ChatGPT

- La API de chat es el requisito previo para todo lo que viene después en esta ruta.
- La novedad es que cualquier programa puede invocar el mismo tipo de modelo que usa ChatGPT.
- Los tres roles comparten la misma ventana de contexto.
- Esto formaliza el turno conversacional como estructura de datos: una lista de mensajes con rol, en vez de texto libre.
