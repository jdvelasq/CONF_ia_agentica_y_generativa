# Warp Agent CLI

- Warp lanzó Warp Agent CLI el 4 de agosto de 2026.
- Fuentes primarias: anuncio de Warp y documentación de la CLI.
- Warp Agent CLI llega después de Claude Code, Codex CLI, Gemini CLI y Qwen Code.
- El agente se ejecuta localmente como programa y sus tools actúan en la máquina o en la sesión SSH conectada.
- La inferencia, sin embargo, normalmente es remota: Warp selecciona o usa el modelo configurado.
