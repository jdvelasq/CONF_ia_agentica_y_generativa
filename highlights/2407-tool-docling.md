# Docling

- En julio de 2024, IBM libera Docling como proyecto open source (MIT) para convertir documentos reales —PDF.
- Hasta entonces, RAG (2005-retrieval-augmented-generation.md) asumía texto ya limpio.
- El cuello de botella de un pipeline RAG rara vez era el embedding o el vector store.
- Cuando se necesitan metadatos académicos (DOI, afiliaciones, referencias bibliográficas) más allá del texto.
- Docling resuelve el parsing y la segmentación como una capa dedicada y reutilizable.
