# Composio Connect

- Composio Connect proporciona una única conexión MCP para acceder a un amplio catálogo de aplicaciones.
- Entre las aplicaciones soportadas están Gmail, Notion, Slack, GitHub, Linear y HubSpot.
- La innovación arquitectónica importante es que no expone miles de herramientas simultáneamente al contexto.
- Este patrón es más importante que el número concreto de integraciones.
- Después, la conexión puede persistir entre sesiones.
