# Humanizer

- No es un modelo ni un detector estadístico de IA.
- Es una skill que guía al agente para revisar texto.
- El procedimiento busca patrones como lenguaje grandilocuente, abstracciones innecesarias.
- Humanizer muestra que una skill puede actuar como editorial policy encoded as procedure.
- Esto conecta con composición de skills: draft → critique → humanize → verify.
