# OpenRouter

- OpenRouter surgió en 2023 para unificar el acceso a modelos ofrecidos por proveedores diferentes.
- Presenta una API compatible con OpenAI y enruta las solicitudes al modelo seleccionado.
- Reduce el coste de integrar APIs heterogéneas y facilita comparar proveedores.
- La unificación no elimina diferencias de precio, disponibilidad, privacidad ni capacidades.
