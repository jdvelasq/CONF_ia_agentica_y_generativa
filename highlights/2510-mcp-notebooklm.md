# NotebookLM / Gemini Notebook MCP

- Existen servidores MCP comunitarios —no oficiales de Google— que conectan agentes como Claude Code con NotebookLM.
- Según la implementación, también puede funcionar con otros clientes MCP.
- Algunas implementaciones comunitarias usan endpoints internos de Google y autenticación por navegador/sesión.
- Los riesgos a considerar incluyen credenciales de Google, dependencia de APIs internas no documentadas.
