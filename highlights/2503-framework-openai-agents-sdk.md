# OpenAI Agents SDK

- OpenAI lanzó el Agents SDK en marzo de 2025 como evolución en producción de Swarm.
- El Agents SDK formaliza ese bucle como una librería.
- El mismo día, OpenAI lanza también la Responses API.
- Un mes después, Google publica su propio framework equivalente, Agent Development Kit (ADK).
- El Runner envía el prompt y el catálogo de tools al modelo, recibe la tool call.
