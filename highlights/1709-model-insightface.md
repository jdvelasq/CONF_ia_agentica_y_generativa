# InsightFace

- InsightFace apareció en 2017 como proyecto de análisis facial 2D y 3D.
- Combina detección de rostros, alineación, representaciones faciales y reconocimiento.
- Sus modelos se reutilizan como componentes de herramientas de reconocimiento y face swapping.
- No es una aplicación de edición de video como FaceFusion o Deep-Live-Cam.
- Código abierto no implica libertad de uso comercial para todos los pesos preentrenados.
