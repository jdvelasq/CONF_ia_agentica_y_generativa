# GitHub Copilot inicial

- GitHub presentó Copilot en junio de 2021 como asistente generativo de programación.
- Basado inicialmente en OpenAI Codex, sugiere líneas y bloques de código desde el contexto del editor.
- A diferencia del autocompletado tradicional, genera propuestas de código, no solo nombres o tokens.
- El desarrollador acepta, rechaza o modifica cada sugerencia; Copilot aún no ejecuta objetivos autónomos.
- Abrió el camino desde asistentes de completado hacia editores y agentes de programación.
