# Model Context Protocol (MCP)

- Anthropic liberó el Model Context Protocol (MCP) como estándar abierto el 25 de noviembre de 2024.
- Lo crearon David Soria Parra y Justin Spahr-Summers en Anthropic.
- MCP se limita al intercambio de contexto: no dicta cómo la aplicación usa el LLM ni cómo gestiona ese contexto.
- Conviene analizar en cada caso dónde quedan datos, credenciales y ejecución.
- Esto es progressive disclosure aplicado a tools, no sólo a documentación.
