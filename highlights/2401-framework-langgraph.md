# LangGraph

- LangChain presentó LangGraph en enero de 2024 para orquestar agentes como grafos de estado.
- Los nodos representan pasos; las aristas permiten rutas condicionales y ciclos explícitos.
- Facilita coordinar herramientas, decisiones y persistencia frente a loops de agente opacos.
- El grafo organiza la ejecución, pero no garantiza que las decisiones del modelo sean correctas.
