# Computer use y browser use

- OpenAI extiende esta misma capacidad hacia un producto orientado a tareas reales con Operator en enero de 2025.
- Browser use es la misma idea aplicada específicamente a navegadores web.
- Muchos sitios modernos consumen endpoints internos para cargar datos.
- Dentro de browser use existen dos patrones de implementación.
- El primero, captura visual, envía al modelo un screenshot de la página para que decida visualmente qué acción tomar.
