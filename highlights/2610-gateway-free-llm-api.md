# Free LLM API

- Los dos proyectos son complementarios, pero cumplen funciones diferentes.
- La propuesta es convertir múltiples cuotas gratuitas pequeñas en una superficie de inferencia agregada.
- Los free tiers pueden cambiar o desaparecer.
- Esto convierte cuotas independientes en una infraestructura de continuidad.
- Cambiar de modelo puede modificar reasoning, tool use, context limits, latency y comportamiento.
