# DALL-E 2

- OpenAI anunció DALL-E 2 en abril de 2022 para generar imágenes desde descripciones de texto.
- Sustituyó el enfoque del DALL-E original por difusión, mejorando calidad y resolución.
- Permite variaciones de imágenes e inpainting para editar regiones mediante instrucciones.
- Su acceso inicial era un servicio cloud cerrado, sin pesos descargables para ejecución local.
- Stable Diffusion abordó después la dependencia de un proveedor cerrado para generar imágenes.
