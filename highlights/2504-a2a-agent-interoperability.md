# Interoperabilidad entre agentes (A2A)

- Google presentó Agent2Agent (A2A) en abril de 2025 para comunicación entre agentes.
- Un agente publica capacidades mediante una agent card y puede recibir tareas de otro agente.
- A diferencia de MCP, orientado a herramientas y recursos, A2A conecta agentes entre sí.
- La interoperabilidad requiere compatibilidad, permisos y controles de seguridad.
