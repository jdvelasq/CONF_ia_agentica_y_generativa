# Asistentes de sistema operativo

- Microsoft anunció en septiembre de 2023 la integración de Copilot en Windows 11.
- Traslada la asistencia generativa desde una app aislada al entorno del sistema operativo.
- El despliegue inicial ofrecía chat y algunas acciones sobre configuraciones del PC.
- La integración no suponía control autónomo general sobre todas las aplicaciones.
