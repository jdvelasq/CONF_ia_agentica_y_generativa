# NVIDIA Nemotron 3 Super 120B-A12B

- El 20 de octubre de 2026, NVIDIA presentó Nemotron 3 Super 120B-A12B.
- El modelo utiliza una arquitectura híbrida con Mixture-of-Experts.
- La activación sparse permite desacoplar parcialmente capacidad total y coste de inferencia.
- Esta distinción evita atribuir al modelo capacidades del stack que lo rodea.
- La familia Nemotron 3 está diseñada para long-context agentic workloads.
