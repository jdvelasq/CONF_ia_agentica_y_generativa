# Qoder

- Alibaba lanzó Qoder el 25 de agosto de 2025: un IDE con capacidades agentic integradas.
- La CLI de Qoder llegó después, el 17 de octubre de 2025.
- Un mes y medio después, en octubre de 2025, Anthropic publica Agent Skills.
- Los documentos 2510-agent-skills-.md de este repositorio profundizan distintos aspectos de ese mecanismo.
- Qoder distingue dos modos de autonomía: Agent Mode, más conversacional y con el humano en el loop en cada paso.
