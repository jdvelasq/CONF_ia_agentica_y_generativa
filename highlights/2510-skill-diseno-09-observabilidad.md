# Agent Skills: observabilidad

- Una skill robusta debe dejar suficiente evidencia para reconstruir qué ocurrió durante su ejecución.
- Cada resultado importante debería poder conectarse con su origen.
- No basta con conocer el resultado final.
- Esto reduce la dependencia de explicaciones post hoc del propio modelo.
- Estas métricas permiten comparar arquitecturas y versiones.
