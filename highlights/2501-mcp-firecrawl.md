# Firecrawl MCP

- Firecrawl MCP conecta agentes compatibles con Model Context Protocol con la infraestructura web de Firecrawl.
- Firecrawl puede convertir URLs a Markdown o JSON estructurado, descubrir URLs.
- Hay solapamiento creciente porque Firecrawl también incorpora interacción con páginas.
- Firecrawl ofrece un MCP remoto y también ejecución local/self-hosted.
- Esto lo convierte en una capa de web data acquisition para agentes.
