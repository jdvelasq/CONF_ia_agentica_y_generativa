# Dyad

- El valor no está solamente en generación de código sino en envolverla en un ciclo de construcción de aplicaciones.
- La integración MCP permite extender el builder con tools y servicios externos.
- El repositorio se presenta como open source; GitHub no expone actualmente un SPDX inequívoco en su metadata.
- Esto reduce lock-in del builder respecto a un modelo o proveedor único.
- La licencia vigente debe revisarse antes de redistribución.
