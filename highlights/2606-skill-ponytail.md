# Ponytail: una skill para eficiencia de agentes de código

- En junio de 2026 se publica Ponytail, una skill/plugin comunitaria para agentes de código.
- No cambia la arquitectura de los modelos ni inventa el concepto de skill.
- Antes, un agente podía resolver una tarea escribiendo código.
- Eso consume tokens de razonamiento y salida, aumenta llamadas al modelo y prolonga la revisión.
- Por tanto, Ponytail no intenta minimizar tokens a cualquier precio: intenta evitar el trabajo innecesario que los gasta.
