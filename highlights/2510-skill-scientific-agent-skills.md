# Scientific Agent Skills

- La especialización se incorpora en el harness mediante skills.
- El número de skills cambia con rapidez y no debe tratarse como una propiedad fija del hito.
- También puede empaquetarse como Agent Plugin.
- Esto convierte las skills en una forma de conocimiento procedural portable.
- El repositorio usa MIT, aunque las skills individuales pueden depender de herramientas o fuentes con licencias propias.
