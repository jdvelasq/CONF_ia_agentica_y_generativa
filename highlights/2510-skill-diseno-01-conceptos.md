# Agent Skills: definición y conceptos

- Este documento cubre qué es una skill, cómo se estructura y en qué nivel del sistema vive.
- Una skill es una carpeta de instrucciones, scripts y recursos que un agente puede descubrir y usar bajo demanda.
- La skill debe cargar sólo el contexto necesario para la tarea.
- El sistema de archivos funciona así como mecanismo de context engineering.
- La description debe escribirse para que el modelo sepa cuándo activar la skill —no como un resumen para humanos.

Este documento cubre qué es una skill, cómo se estructura y en qué nivel del sistema vive, como base conceptual para el resto de la guía `2510-skill-diseno-*`.
