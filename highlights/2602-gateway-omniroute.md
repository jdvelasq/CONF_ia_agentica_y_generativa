# OmniRoute

- OmniRoute apareció en febrero de 2026 como gateway local para varios proveedores de LLM.
- Expone una API compatible con OpenAI y enruta solicitudes según su configuración.
- Incluye un servicio local y una interfaz para administrar rutas y proveedores.
- Centralizar llamadas no elimina las diferencias de cuotas, privacidad y disponibilidad.
