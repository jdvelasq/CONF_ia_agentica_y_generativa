# Awesome Free LLM APIs

- El repositorio no proporciona por sí mismo miles de millones de tokens ni ejecuta los modelos.
- En octubre de 2026 declara más de 130 APIs gratuitas de más de 40 proveedores.
- Una de las aplicaciones más llamativas es utilizar Claude Code con modelos alternativos.
- La interfaz/harness puede seguir siendo Claude Code mientras el modelo que responde procede de otro proveedor.
- Los tiers tienen límites distintos por requests, tokens, minuto, día o mes, y pueden cambiar o desaparecer.
