# Perplexity MCP

- El 10 de marzo de 2025 Perplexity publicó su servidor MCP oficial (perplexityai/modelcontextprotocol, MIT).
- Antes, la investigación con fuentes citadas vivía dentro de productos cerrados.
- El agente que escribía código, analizaba datos o redactaba no podía llamar a esa investigación por sí mismo.
- Las búsquedas web que traían algunos agentes daban enlaces sueltos.
- Al principio (marzo de 2025) el servidor ofrecía perplexity_ask sobre el modelo sonar-pro.
