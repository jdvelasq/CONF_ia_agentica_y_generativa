# gpt-oss

- Ambos son modelos Mixture-of-Experts orientados a razonamiento, tool use y workflows agentic.
- Ambos modelos se entrenaron con precisión nativa MXFP4 en las capas MoE.
- Semanas después, Alibaba presenta Qoder: un IDE agentic completo, un registro distinto al de un modelo abierto.
- La variante de 120B apunta a un único GPU de datacenter (OpenAI sugiere un H100 de 80 GB).
- Las dos rutas de abajo ejecutan el modelo localmente, en tu propia máquina, sin llamar a la API cloud de OpenAI.
