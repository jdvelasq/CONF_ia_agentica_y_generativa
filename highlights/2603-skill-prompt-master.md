# Prompt Master: diseño de instrucciones para herramientas de IA

- Antes, una persona debía recordar por sí misma qué contexto, restricciones.
- Un prompt mejor no compensa requisitos mal entendidos ni sustituye la inspección del entorno real.
- Perfiles de prompting desactualizados también pueden introducir recomendaciones erróneas.
- El problema es la ambigüedad operacional: una instrucción puede expresar una intención válida.
- El valor práctico es reducir iteraciones evitables y hacer explícito el contrato de una solicitud.
