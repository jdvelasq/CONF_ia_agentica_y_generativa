# Prompt injection, jailbreaks y trust boundaries

- A medida que los LLM evolucionan desde chatbots hacia agentes conectados a correo.
- Sin embargo, ambos terminan representados como tokens dentro del contexto del modelo.
- La inyección indirecta puede llegar desde webpages, email, documentos.
- Por eso la autoridad no debe depender únicamente del juicio del modelo.
- La seguridad moderna no puede reducirse a que el modelo aprendió a responder "I can't".
