# Microsoft-Decision-1

- Microsoft anunció Microsoft-Decision-1 el 9 de octubre de 2026.
- Es un modelo para decisiones estructuradas de baja latencia, no un LLM conversacional general.
- Recibe estados estructurados, evalúa alternativas y produce decisiones.
- Microsoft señaló pruebas en respuesta a incidentes, control de calidad y descubrimiento científico.
- Su anuncio llevó la categoría de decision models al catálogo de un gran proveedor cloud.
- Para evaluarlo importan latencia, calibración, esquema de API, integración y disponibilidad local.
