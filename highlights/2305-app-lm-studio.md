# LM Studio

- LM Studio apareció en 2023 como aplicación gráfica para descargar y ejecutar LLM localmente.
- Reduce la necesidad de compilar runtimes o manejar directamente una CLI.
- Ofrece chat con modelos locales y un servidor de API para aplicaciones compatibles.
- La ejecución sigue limitada por memoria, formato de pesos y rendimiento del equipo.
