# ChatGPT Agent

- OpenAI presentó ChatGPT Agent en julio de 2025 para ejecutar tareas de varios pasos.
- Combina investigación, navegación web y acciones en un mismo flujo conversacional.
- Integra capacidades antes separadas entre Operator y deep research.
- Las acciones requieren controles y supervisión; la autonomía no garantiza éxito ni seguridad.
