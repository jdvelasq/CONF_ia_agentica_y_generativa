# Open WebUI

- Por una disputa de marca con el equipo de Ollama, el proyecto se renombra a Open WebUI a comienzos de 2024.
- Open WebUI no tiene modelos propios; es sólo la interfaz.
- Open WebUI es la contraparte de interfaz gráfica de Ollama (2307-runtime-ollama.md).
- Cuando el chat necesita trabajar sobre documentos propios con cita verificable en vez de un prompt suelto.
- Repositorio oficial: github.com/open-webui/open-webui.
