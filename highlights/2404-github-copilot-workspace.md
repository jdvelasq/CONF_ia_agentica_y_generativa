# GitHub Copilot Workspace

- A partir de un issue de GitHub, Copilot Workspace genera una especificación en lenguaje natural.
- GitHub cerró el technical preview de Copilot Workspace el 30 de mayo de 2025: el producto como tal fue descontinuado.
- El patrón que hizo visible —issue → especificación → plan → cambios de código— sigue vivo.
- GitHub, "GitHub Copilot Workspace", 2024-04-29.
