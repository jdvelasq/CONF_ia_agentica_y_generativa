# Obsidian Agent Skills

- En enero de 2026, Steph Ango (kepano), CEO de Obsidian, publicó obsidian-skills.
- Esto evita depender exclusivamente de una API propietaria.
- La skill convierte conocimiento tácito/documentación en procedimiento agent-readable.
- Obsidian Bases permite crear vistas estructuradas sobre notas y propiedades.
- Esto transforma al agente de simple editor Markdown en constructor de interfaces sobre conocimiento estructurado.
