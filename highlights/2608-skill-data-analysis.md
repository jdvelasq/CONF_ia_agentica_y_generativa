# Data Analysis Skills: producir y revisar de forma independiente

- GitHub registra la creación de ajrcre/data-analysis-skills el 4 de agosto de 2026.
- No introduce las skills ni la revisión de resultados.
- El flujo exige definir intención, alcance y periodo antes de consultar.
- Cada ejecución queda sellada en su propia carpeta.
- Al terminar, el análisis lanza un subagente con contexto limpio que ejecuta la revisión.
