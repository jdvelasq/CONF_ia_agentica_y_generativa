# Everything Claude Code (ECC)

- Everything Claude Code (ECC), de Affaan Mustafa (ganador de un hackathon de Anthropic).
- Antes de este hito, extender un coding agent significaba sobre todo ensamblar manualmente hooks.
- ECC empaqueta ese ensamblaje en un catálogo instalable.
- Aunque nació alrededor de Claude Code, declara soporte —desigual— para múltiples harnesses.
- Las cifras de contenido cambian de versión a versión (decenas de agentes, cientos de skills, decenas de command shims).
