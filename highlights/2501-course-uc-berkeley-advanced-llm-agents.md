# UC Berkeley: Advanced Large Language Model Agents

- UC Berkeley ofreció Advanced Large Language Model Agents en el semestre de primavera de 2025.
- El curso profundizó en razonamiento, planificación, búsqueda y verificación de código.
- Señala el paso de cursos introductorios de agentes a formación universitaria especializada.
- Es un hito educativo, no el lanzamiento de un nuevo modelo o protocolo.
