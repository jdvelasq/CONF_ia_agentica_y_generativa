# Claude Cowork: delegar tareas de trabajo, no sólo de código

- En enero de 2026 Anthropic lanzó Claude Cowork como research preview.
- El usuario da un objetivo y Claude trabaja sobre archivos y herramientas hasta devolver un resultado para revisión.
- Antes, delegar a Claude trabajo de varios pasos exigía Claude Code o armar un agente propio.
- Cowork llevó ese bucle agentic a tareas de oficina (analizar, redactar.
- La delegación desde otras superficies (móvil, nube) lleva a los agentes alojados.
