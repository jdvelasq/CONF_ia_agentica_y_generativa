# Stable Diffusion

- En agosto de 2022, Stable Diffusion liberó pesos de un modelo de difusión latente texto-a-imagen.
- A diferencia de DALL-E 2, permite generar imágenes en hardware propio sin API cloud obligatoria.
- Habilita texto-a-imagen, imagen-a-imagen y flujos de edición y variación visual.
- La ejecución local depende de memoria, compatibilidad del runtime y condiciones de licencia.
- Generar imágenes no convierte al modelo en agente ni le da acceso autónomo a herramientas.
