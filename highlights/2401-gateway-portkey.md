# Portkey AI Gateway: gateway open source con routing declarativo y guardrails

- El 9 de enero de 2024 Portkey publicó como open source su AI Gateway (Portkey-AI/gateway, MIT, escrito en TypeScript).
- Hasta entonces era la capa interna de su producto comercial de observabilidad para LLMs.
- Para esa fecha ya existían OpenRouter (mar-2023, un marketplace hospedado) y LiteLLM (jul-2023.
- El anuncio prometía unos 200 LLMs detrás de una sola API, routing multimodal (visión.
- Los configs se anidan: un target puede ser a su vez otro config.
