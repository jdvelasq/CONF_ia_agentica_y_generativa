# Scrapling

- La infografía que lo recomienda para Claude lo rotula simplemente como "Scraping"; el proyecto real es Scrapling.
- Scrapling es una tool, no una Agent Skill ni un agente por sí mismo.
- La tool convierte la web en una fuente de observaciones estructuradas.
- La capacidad técnica de extraer contenido no implica permiso para hacerlo.
- Deben respetarse términos de servicio, autenticación, privacidad, copyright.
