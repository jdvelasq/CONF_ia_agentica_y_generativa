# OpenAI dots

- El recap oficial de OpenAI del 29 de septiembre de 2026 agrupa varios anuncios del ecosistema agentic.
- Además de Dots, incluye referencias a Decisions API, computer use en Agents API.
- No se crea una carpeta raíz 2026-09-devday-2026 porque DevDay es un evento que agrupa varias capacidades.
- Los "dots" son una implementación posterior del patrón de agente personal persistente en la nube.
- Cada dot corre en un entorno propio en cloud, mantiene contexto entre conversaciones.
