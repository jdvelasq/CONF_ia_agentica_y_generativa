# Realtime API

- OpenAI presentó la Realtime API en beta pública el 1 de octubre de 2024.
- Antes de este hito, construir un asistente de voz conversacional requería encadenar tres pasos independientes.
- La Realtime API expone un modelo que procesa y genera audio directamente.
- STT → LLM → TTS deja de ser la única arquitectura práctica para voz conversacional de baja latencia.
- OpenAI, "Introducing the Realtime API", 2024-10-01.
