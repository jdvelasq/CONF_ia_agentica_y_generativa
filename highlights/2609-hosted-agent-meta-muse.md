# Meta Muse

- Muse es un agente personal persistente operado por Meta.
- No corresponde a model-: el modelo subyacente puede cambiar.
- Muse es el agente; WhatsApp es un canal o superficie; Muse Secure VM es el entorno de ejecución cloud donde corre.
- Vale la pena observar su persistencia, memoria, acciones disponibles.
