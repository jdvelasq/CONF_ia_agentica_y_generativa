# Claude-Mem

- El mismo mes, OpenAI libera gpt-oss: el regreso de OpenAI a los modelos de pesos abiertos.
- Declara soporte para varios agentes además de Claude Code (OpenCode, Codex, Gemini CLI, Copilot, entre otros).
- Aporta continuidad entre sesiones, resúmenes semánticos y menos necesidad de reexplicar contexto manualmente.
- Memoria útil da continuidad; memoria irrelevante o excesiva es ruido de contexto.
- Por eso importan la recuperación selectiva, la compresión y la trazabilidad, no sólo la acumulación.
