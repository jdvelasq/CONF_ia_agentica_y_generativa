# GitHub Copilot X

- GitHub anunció Copilot X en marzo de 2023 como evolución del asistente de completado de 2021.
- Propuso chat contextual, ayuda en pull requests, documentación y terminal.
- La asistencia se amplía desde sugerir código a acompañar varias etapas del desarrollo.
- El anuncio describe una visión y vistas previas; no todas las funciones llegaron juntas.
