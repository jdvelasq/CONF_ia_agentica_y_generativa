# OpenClaw

- OpenClaw corre como proceso en segundo plano (daemon) y mantiene memoria entre sesiones.
- Según Turing Post, el gateway es un plano de control que gestiona sesiones.
- Memoria en archivos Markdown como fuente de verdad, con recuperación híbrida (embeddings y palabras clave).
- Un "heartbeat" despierta al agente según un horario para que actúe sin instrucciones.
- Configuración manual, basada en archivos y muy explícita.
