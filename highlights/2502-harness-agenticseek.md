# agenticSeek

- El proyecto enfatiza el uso de modelos locales mediante Ollama, LM Studio o servidores OpenAI-compatible.
- Incluye navegación, planificación/razonamiento, ejecución de código, sesiones y herramientas.
- El proyecto documenta controles como token para backend, restricciones de hosts.
- Importar un perfil de navegador puede además exponer cookies, passwords/autofill y sesiones al entorno del agente.
