# GitHub Copilot coding agent

- GitHub presentó Copilot coding agent en public preview el 19 de mayo de 2025.
- Llega pocos días después de que OpenAI lanzara Codex (16 de mayo de 2025) con el mismo patrón de agente cloud delegado.
- El mismo mes, Xiaomi MiMo amplía el ecosistema de modelos abiertos de razonamiento pequeños.
- La limitación abierta es la misma que comparten todos los agentes cloud de esta generación.
- GitHub, "Meet the new coding agent", 2025-05-19.
