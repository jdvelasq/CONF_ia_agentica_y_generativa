# GPT-4V y multimodalidad

- El 25 de septiembre de 2023, OpenAI pone GPT-4V (GPT-4 with Vision) a disposición de los usuarios de ChatGPT Plus.
- El acceso para desarrolladores vía API llega después, en el DevDay del 6 de noviembre de 2023.
- GPT-4 (mar-2023, 2303-model-gpt-4.md) ya anunciaba esta capacidad como research preview.
- GPT-4V prepara el terreno para comprensión de documentos, browser use y computer use.
