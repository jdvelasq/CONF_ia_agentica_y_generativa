# Olla

- El proyecto está escrito en Go y se distribuye como un binario ligero.
- Por tanto, Olla puede situarse delante de Ollama, pero no lo reemplaza como motor de inferencia.
- Olla puede reducir el overhead de la propia capa de proxy y facilitar una infraestructura eficiente.
- Esto permite cambiar infraestructura de inferencia sin modificar cada agente individualmente.
