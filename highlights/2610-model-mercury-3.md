# Mercury 3: diffusion LLM at 1,000+ tokens/s

- Inception anunció Mercury 3 el 19 de octubre de 2026 como modelo de lenguaje por difusión.
- A diferencia de los LLM autorregresivos, refina varios tokens en paralelo.
- Inception reportó 1.068 tokens/s en GPUs NVIDIA y una ventana de contexto de 1 millón de tokens.
- La velocidad reportada depende de infraestructura y carga; no es una latencia garantizada.
- La menor latencia puede acelerar bucles de agentes que alternan observación, decisión y herramientas.
- Los resultados de agentes web y las comparaciones con otros modelos proceden de pruebas reportadas.
- Mercury 3 ofrece API compatible con OpenAI; precio y promociones son condiciones cambiantes.
