# Stirling PDF

- Antes de este hito, manipular PDFs localmente (firmar, redactar, convertir.
- En 2024 el proyecto recibe financiación de Open Core Ventures y adopta un modelo open-core.
- Internamente combina LibreOffice, Tesseract y qpdf detrás de un backend Spring Boot.
- Cubre merge/split, conversión, compresión, edición, firma, redacción, OCR y automatización/workflows.
- El "AI engine" (stirling_ai) es una función de Stirling Cloud y no está disponible en despliegues self-hosted.
