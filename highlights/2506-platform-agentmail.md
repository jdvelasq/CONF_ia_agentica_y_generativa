# AgentMail: email e identidad para agentes

- En 2025 aparece AgentMail, un proveedor de correo construido específicamente para agentes de IA.
- AgentMail no es principalmente un asistente que se conecta a una cuenta humana.
- Cada inbox posee una dirección real y soporta conversaciones bidireccionales.
- La infraestructura también puede utilizarse mediante: REST API; Python SDK; TypeScript SDK; CLI; MCP server; IMAP; SMTP.
- La tesis más importante de AgentMail no es correo, sino identidad para agentes.
