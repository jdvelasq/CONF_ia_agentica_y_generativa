# Llama 3

- Meta lanzó Llama 3 en abril de 2024 con modelos iniciales de 8B y 70B parámetros.
- Distribuyó pesos base e instruct para ejecutar y adaptar modelos fuera de una API cerrada.
- La licencia comunitaria permite usos amplios, pero no equivale a una licencia open source OSI.
- La disponibilidad de pesos no elimina los requisitos de memoria y cómputo.
