# Task Observer: observación deliberada para mejorar skills

- Un log puede acumular ruido, sesgos del modelo o reglas contradictorias.
- Requiere curaduría humana, criterios de promoción y validación antes de actualizar una skill.
- El desarrollo posterior es cerrar ese ciclo con pruebas, evaluación y control de versiones de las instrucciones.
- El problema es perder la evidencia que revela dónde una biblioteca de skills es insuficiente.
- La skill se activa al inicio de sesiones orientadas a tareas mediante instrucciones del proyecto o un hook de sesión.
