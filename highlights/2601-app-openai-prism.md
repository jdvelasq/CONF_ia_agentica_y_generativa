# Prism (OpenAI for Science)

- El 27/28 de enero de 2026 OpenAI lanzó Prism: un workspace de escritura científica nativo en LaTeX.
- Nace de Crixet, una plataforma de LaTeX que OpenAI adquirió y transformó en este producto.
- Gratuito para cuentas personales de ChatGPT; versiones para empresas, universidades y organizaciones llegarán después.
