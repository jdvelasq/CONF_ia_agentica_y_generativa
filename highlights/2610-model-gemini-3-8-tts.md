# Gemini 3.8 Flash TTS

- En octubre de 2026 Google introduce Gemini 3.8 Flash TTS y Gemini 3.8 Flash-Lite TTS.
- El texto se mantiene como transcript literal y las instrucciones de interpretación se separan mediante metadata y tags.
- Cada turno puede tener identidad y estilo propios.
- Esto evita insertar instrucciones escénicas dentro del texto que debe pronunciarse.
- Esto es importante para producción de podcasts, audiolibros, narración y contenido multi-turn.
