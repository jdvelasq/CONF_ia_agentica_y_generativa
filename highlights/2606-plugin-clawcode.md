# ClawCode

- No es un harness independiente como OpenClaw (2602-harness-openclaw.md).
- La identidad del agente se mantiene en tres archivos —SOUL.md, IDENTITY.md.
- Puede conectarse mediante plugins MCP a WhatsApp, Telegram, Discord.
- El proyecto recomienda scope local para aislar cada agente en su propia carpeta.
