# openai/skills: catálogo de skills para Codex

- GitHub registra la creación de openai/skills el 25 de noviembre de 2025.
- Es el catálogo de OpenAI para usar y distribuir skills con Codex, bajo el mismo formato SKILL.md (Agent Skills).
- Muestra que el formato cruzó de Anthropic a otro proveedor mayor, antes de que el estándar abierto se especificara.
- El catálogo se organiza por nivel de confianza.
- Se acepta si se registra la versión instalada y el efecto observado.
