# ChatGPT Work

- OpenAI lanzó ChatGPT Work en julio de 2026 como espacio para delegar trabajo prolongado.
- Permite trabajar con archivos, aplicaciones conectadas y navegación en flujos de varios pasos.
- El objetivo cambia de responder una consulta a entregar un resultado de trabajo terminado.
- La ejecución depende de accesos, permisos y supervisión de las acciones realizadas.
