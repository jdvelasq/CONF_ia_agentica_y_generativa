# Headroom

- Headroom es una capa de context compression que reduce el volumen de información enviado al modelo.
- Puede utilizarse como library, proxy, wrapper de agentes o servidor MCP.
- Incluye integración con harnesses y coding agents como Claude Code.
- Una parte puede ser repetitiva, estructuralmente redundante o irrelevante para la siguiente decisión.
- Por tanto, su función no es mejorar el prompt del usuario sino optimizar el contexto operacional del agente.
