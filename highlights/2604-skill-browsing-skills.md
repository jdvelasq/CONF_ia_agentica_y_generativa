# Browsing Skills: acciones de sitios web como interfaces estructuradas

- GitHub registra la creación de browsing-skills/browsing-skills el 18 de abril de 2026.
- Es una biblioteca de skills específicas por sitio web.
- Antes, un agente de navegador exploraba la página, inspeccionaba volcados del DOM.
- Con una skill por sitio, el agente carga la referencia de la acción apropiada.
- El proyecto reporta una comparación propia en una búsqueda de Booking.com.
