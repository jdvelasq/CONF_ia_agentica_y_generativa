# Memoria y estado: ChatGPT Memory

- Antes de este hito, cada conversación con ChatGPT empezaba desde cero.
- La memoria personal introduce el ciclo usuario → interacciones → memoria persistente → conversaciones futuras.
- Mecanismos equivalentes aparecieron después en otros productos (Claude Memory, memoria de Gemini).
- La pregunta local-first asociada es dónde se almacena ese estado.
