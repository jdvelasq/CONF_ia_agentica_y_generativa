# Vibe coding: programar por intención y resultado observable

- Reduce el costo inicial de transformar una idea en software ejecutable cuando escribir.
- Para docencia y trabajo exploratorio, permite convertir una pregunta.
- Las herramientas de código con IA podían sugerir, completar o generar fragmentos.
- Vibe coding no es sinónimo de todo desarrollo asistido por IA ni de ingeniería de software agentic.
- Esto baja la barrera para explorar ideas, construir prototipos, automatizaciones personales y herramientas internas.
