# Deep Agents

- LangChain liberó deepagents en julio de 2025 como framework abierto sobre LangGraph.
- Reúne planificación, uso de archivos y delegación a subagentes para tareas largas.
- Traslada patrones de asistentes como Claude Code a aplicaciones de propósito general.
- El framework aporta estructura, no autonomía fiable sin evaluación y herramientas adecuadas.
