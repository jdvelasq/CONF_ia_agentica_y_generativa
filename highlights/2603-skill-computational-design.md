# Computational Design Skills: conocimiento de dominio como plugin de skills

- GitHub registra la creación de Abhinavbwj/Claude-skills-for-Computational-Designers el 26 de marzo de 2026.
- Es un plugin de Claude Code con 18 skills interconectadas para diseño computacional en AEC.
- No introduce el formato de skills (2510-skill-agent-skills.md).
- El dominio deja de depender de prompts ad hoc y pasa a ser un plugin instalable con cálculos deterministas.
- Incluye también una skill design-automation con reglas, plantillas paramétricas.
