# Vercel Agent Browser

- Vercel Labs publicó Agent Browser a comienzos de 2026 como CLI de automatización web.
- Proporciona comandos para que agentes interactúen con un navegador desde la terminal.
- Puede integrarse con distintos asistentes de código, no solo con un proveedor.
- La automatización depende del estado de la página y de controles de permisos.
