# Langflow

- Langflow apareció en marzo de 2023 para diseñar aplicaciones LLM mediante componentes visuales.
- Conecta modelos, prompts, memoria y herramientas sin escribir toda la orquestación en Python.
- Hace visible la estructura de cadenas construidas sobre LangChain.
- El diseño visual no sustituye pruebas, evaluación ni mantenimiento de las integraciones.
