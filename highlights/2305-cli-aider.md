# Aider

- Antes de Aider, la asistencia de código vivía casi siempre dentro de un IDE (Copilot, y poco después Continue).
- Aider se ubica en una secuencia de asistentes de código cada vez más autónomos.
- Para evitar ambigüedad conviene indicar el modelo explícitamente, incluyendo modelos locales servidos por Ollama.
- La integración con Git es el concepto central.
- La limitación es la misma de cualquier asistente de esta generación.
