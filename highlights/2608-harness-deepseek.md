# DeepSeek Harness

- DeepSeek Harness (dsh) es un agent harness open source desarrollado por DeepSeek AI.
- Combina modelo, agent loop, tools, sessions, plugins y UI/SDK/ACP en un agente ejecutable.
- Todos sus componentes —model adapter, tool registry, session log, agent loop.
- Aunque el harness es de DeepSeek AI, los model adapters son también plugins.
