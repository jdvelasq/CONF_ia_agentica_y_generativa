# Qwen Code

- Alibaba publicó Qwen Code el 23 de julio de 2025, junto con el modelo Qwen3-Coder.
- Un mes después, en agosto de 2025, aparece Claude-Mem.
- La configuración vive en ~/.qwen/ (usuario) y /.qwen/ (proyecto).
- Aunque está optimizado para los modelos Qwen, puede trabajar con otros proveedores o con servidores locales compatibles.
- Qwen Code usa MCP para conectar tools externas.
