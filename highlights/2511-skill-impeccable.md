# Impeccable: criterio y verificación de UI para agentes

- Impeccable se publica en noviembre de 2025 como una skill para que agentes de código diseñen.
- Antes, un agente podía generar HTML, CSS y componentes.
- Los detectores reducen problemas repetibles, pero no sustituyen investigación con usuarios.
- El patrón que queda abierto es integrar contexto de producto, generación.
