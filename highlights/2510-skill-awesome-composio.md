# Awesome Claude Skills (Composio): el primer hub comunitario de skills

- GitHub registra la creación de ComposioHQ/awesome-claude-skills el 17 de octubre de 2025.
- Es una lista curada que hoy declara más de 1.000 skills y plugins.
- Antes de un hub, encontrar una skill implicaba buscar repositorios sueltos.
- Una lista categorizada convierte el descubrimiento en navegación y fija un vocabulario común (skill, plugin, SKILL.md).
- Es una oferta comercial del autor de la lista; la separación conceptual es independiente de ese producto.
