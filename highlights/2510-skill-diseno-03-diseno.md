# Skills: diseño

- Una skill útil debe diseñarse como un componente reusable y componible de un sistema agéntico.
- La diferencia es que una skill suele contener comportamiento probabilístico mediado por un LLM.
- No conviene dar a un agente una meta amplia y esperar que llegue por sí solo al estado correcto.
- La autonomía queda contenida dentro de etapas verificables.
- Una skill debe tener una responsabilidad suficientemente clara como para poder reutilizarse y combinarse con otras.
