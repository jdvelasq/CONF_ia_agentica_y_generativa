# Claude 3

- El 4 de marzo de 2024 Anthropic lanzó la familia Claude 3.
- Es la primera generación de Claude con multimodalidad (entiende imágenes.
- Antes de Claude 3, elegir Claude significaba un solo modelo con un solo trade-off de costo/capacidad.
- En mayo de 2025, Claude 4 deja atrás la numeración 3.x y marca el salto de generación que sostiene Claude Code.
