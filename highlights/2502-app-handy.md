# Handy

- En febrero de 2025 aparece cjpais/Handy, una aplicación open source de speech-to-text completamente offline para macOS.
- La aplicación utiliza Tauri, React/TypeScript y backend Rust, con inferencia local.
- No es un agente ni un LLM application completo.
- Es una capa local de percepción/entrada que puede alimentar chats, IDEs y agentes.
- Esto reduce exposición de audio y elimina dependencia de APIs de transcripción.
