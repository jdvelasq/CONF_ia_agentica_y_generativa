# Continue

- Continue es una extensión de código abierto para asistencia de código.
- A diferencia de Copilot (cerrado, integrado sólo a su propio backend).
- En esta etapa interesa como asistente de código reactivo.
- La capacidad de Agent (loop más autónomo) corresponde a una etapa posterior y no se trata aquí.
- Continue puede usarse desde VS Code, JetBrains o desde la CLI (cn).
