# DeepCode

- DeepCode trata la reproducción científica como un proceso cerrado de ingeniería, no como una generación one-shot.
- Esta separación permite controlar el flujo de información bajo ventanas de contexto finitas.
- Este diseño es un caso directo de loop engineering.
- La terminación no debería depender únicamente de que el modelo declare "done".
- DeepCode conserva: tool activity; cambios; tests; artifacts; verification evidence.
