# Google Agent Development Kit (ADK)

- Google presentó Agent Development Kit (ADK) en abril de 2025 como framework open-source para construir sistemas agentic.
- La idea clave que comparte con los demás SDKs de esta generación es que modelo ≠ agente.
- ADK permite organizar un agente principal con subagentes especializados, tools, sesiones/estado, callbacks y evaluación.
