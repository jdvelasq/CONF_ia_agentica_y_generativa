# OpenJarvis

- OpenJarvis es un framework open source (licencia Apache 2.0) para personal AI local-first.
- El repositorio se abrió el 15 de febrero de 2026 y alcanzó la versión 1.0.0 el 16 de mayo de 2026.
- Es framework más runtime agentic más agentes incorporados más skills más evaluación más trazas.
- El instalador configura uv, el entorno Python, Ollama y un modelo inicial.
- Presets: chat-simple, deep-research, code-assistant, scheduled-monitor, morning-digest.
