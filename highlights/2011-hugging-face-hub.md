# Hugging Face Hub: repositorios versionados para modelos

- En noviembre de 2020, Hugging Face consolidó un repositorio Git versionado por modelo.
- Cada repositorio puede reunir pesos, tokenizer, configuración, licencia y documentación.
- El Hub facilita descubrir, descargar y reutilizar modelos con versiones identificables.
- Publicar pesos no equivale a ejecutarlos: se requiere una biblioteca o runtime compatible.
- La distribución de modelos facilita su ejecución local, sujeta a hardware, formato y licencia.
