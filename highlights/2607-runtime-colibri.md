# colibrì

- En un modelo Mixture-of-Experts, la parte densa permanece en RAM/GPU.
- El engine está escrito en C puro, por lo que funciona en CPU sin GPU.
- El proyecto declara soporte para familias como GLM-5.2/5.3, GLM-5.3-Flash.
- Incluye también un MCP server (coli mcp) con herramientas para detectar hardware.
