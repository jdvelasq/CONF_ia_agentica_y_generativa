# Hermes Agent

- Es model-agnostic (puede apuntar a Claude, GPT o modelos locales) y se alcanza desde mensajería —Telegram.
- Una capacidad distintiva es que puede convertir tareas ya resueltas en skills reutilizables.
- Tratar las cifras de descargas y valoración como reportadas por la compañía y la prensa.
- Automatización: cron con trabajos en ~/.hermes/cron/jobs.json, ejecutados en sesiones aisladas.
- No se verificó cuál describe el estado vigente del CLI.
